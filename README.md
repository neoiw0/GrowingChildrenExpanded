# Growing Children Expanded — Player Wiki

**Version 2.9.43** · Player-facing documentation only

Growing Children Expanded is an independent, player-facing expansion that runs **alongside** the Growing Children mod. It adds parent bond, six personalities, work & travel improvements, health & breakfast, festivals & letters, boots and backpack auto-wear, a settings page, and safe uninstall — while keeping Growing Children's identity, growth, jobs, and daily reports as the foundation.

《Growing Children Expanded》是《Growing Children》的独立附加模组，本仓库存放其玩家向 Wiki。它依赖 Growing Children 运行，不改写其任何文件，不包含其资产，可干净卸载。
